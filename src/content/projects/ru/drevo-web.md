## Что это

**Древо** — открытая православная энциклопедия (wiki), православный аналог
Википедии со своими особенностями: статьи, новости, форум и справочные разделы,
преимущественно на русском языке. Работает с 2005 года.

Сайт прошёл несколько поколений движка: изначально написан с нуля на голом
**PHP**, затем переписан на **Yii**. Сейчас идёт крупный рефакторинг: новый
фронтенд на **Angular** постепенно замещает страницы legacy-сайта, а старое
приложение на **Yii** при этом выступает бэкендом — отдаёт данные новому фронту
по API.

## Стек

Legacy-сайт — **Yii Framework 1.x** (**PHP 8.5+**), при доработках код
подтягивается к современным стандартам PHP (строгая типизация, PSR-4, PHPUnit).

Новый фронтенд — **Nx**-монорепо с приложением на **Angular 21**: **RxJS**,
**Angular Signals**, **Angular Material** (M3), редактор на **CodeMirror 6**, SSR
на **Express**, unit-тесты на **Jest + Spectator**, e2e на **Playwright**,
мониторинг через **Sentry**. Пакетный менеджер — **Yarn**.

## Моя роль

Полностью мой проект: **придумал, разработал и администрирую** сайт.

- Веду **миграцию с legacy Yii1 на Angular**: legacy-приложение при этом работает
  как бэкенд для нового фронтенда.
- Собрал **Nx-монорепо** — приложение `client` и библиотеки `core`, `shared`,
  `ui`, `editor`.
- Модернизирую **legacy-бэкенд на Yii**: перевожу код на современный PHP и
  покрываю PHPUnit-тестами.
- Настроил **CI/CD на GitHub Actions** (beta-деплой по push, release по тегам),
  unit- и e2e-тестирование, мониторинг через Sentry.
