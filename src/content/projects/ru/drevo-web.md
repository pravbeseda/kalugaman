## Что это

**Древо** — открытая православная энциклопедия (wiki), православный аналог
Википедии со своими особенностями: статьи, новости, форум, иллюстрации, православный календарь,
преимущественно на русском языке. Работает с 2005 года.

Сайт прошёл несколько поколений движка: изначально написан с нуля на голом
**PHP**, затем переписан на **Yii**. Сейчас идёт крупный рефакторинг: новый
фронтенд на **Angular** — отдельное приложение на `app.drevo-info.ru` — раздел за
разделом повторяет функциональность legacy-сайта, а старое приложение на **Yii**
при этом выступает бэкендом и отдаёт данные новому фронту по REST API. Пока
новый фронтенд открыт для авторизованных пользователей.

Уже перенесены: просмотр статей с историей версий и сравнением, редактор статей
с черновиками, иллюстрации с загрузкой и модерацией, премодерация правок, поиск,
православный календарь и форум (пока на чтение). Редактор нового фронтенда
встроен и в legacy-сайт. Главная и новости — на очереди.

## Стек

Legacy-сайт — **Yii Framework 1.1** (**PHP 8.5+**), при доработках код
подтягивается к современным стандартам PHP: строгая типизация, PSR-4,
**PHPUnit**, **PHPStan** (строгий уровень для нового кода, baseline для старого,
который может только уменьшаться), PHP-CS-Fixer, версионированные миграции БД.

Новый фронтенд — **Nx**-монорепо с приложением на **Angular 22** (zoneless) и
**TypeScript 6**: **RxJS**, **Angular Signals**, **Angular Material** (M3),
редактор на **CodeMirror 6**, черновики в IndexedDB через Dexie, SSR на
**Express 5** для страниц статей, unit-тесты на **Jest + Spectator**, два набора
**Playwright**-тестов — интеграционный с моками API и e2e против реального
бэкенда, мониторинг через **Sentry**. Качество держат ESLint со строгими
типизированными правилами, порог type coverage около 100% и порог покрытия
тестами. Пакетный менеджер — **Yarn**.

## Моя роль

Полностью мой проект: **придумал, разработал и администрирую** сайт.

- Веду **миграцию с legacy Yii1 на Angular**: legacy-приложение при этом работает
  как бэкенд для нового фронтенда.
- Собрал **Nx-монорепо** — приложение `client` и библиотеки `core`, `shared`,
  `ui`, `editor`.
- Модернизирую **legacy-бэкенд на Yii**: строю REST API для нового фронтенда,
  перевожу код на современный PHP, покрываю PHPUnit-тестами, закрываю
  уязвимости, написал спам-фильтр для форума.
- Настроил **CI/CD на GitHub Actions**: для фронтенда — beta-деплой по push в
  `main` и release по тегам, для бэкенда — тесты, статический анализ и аудит
  зависимостей на каждый PR.
