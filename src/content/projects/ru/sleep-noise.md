## Что это

Приложение для засыпания под шум: **белый** и **коричневый** шум с независимой
регулировкой громкости — их можно слушать по отдельности или смешивать в нужной
пропорции. Есть **таймер сна** с шагом в полчаса: по его истечении звук
выключается сам. Настройки — громкость каждого шума, значение таймера, тема —
сохраняются между запусками.

Ключевое решение: звук не проигрывается из файлов, а **синтезируется в реальном
времени**. Отсюда крошечный размер приложения, отсутствие слышимых стыков на
зацикливании и возможность звучать сколь угодно долго. Приложение бесплатное,
без рекламы.

## Стек

**Kotlin**, **Android SDK** (minSdk 24, targetSdk 36), UI на XML-layout'ах с
**Material Components**. Звук — низкоуровневый **AudioTrack** в режиме streaming
(PCM 16 бит, 44,1 кГц, моно): генератор наполняет буфер сэмплами в отдельном
потоке с максимальным приоритетом, состояние воспроизведения синхронизировано
через `AtomicBoolean`. Белый шум — равномерный случайный сигнал, коричневый —
интегрированный белый с ограничением амплитуды. Плюс **Firebase** (Analytics,
Crashlytics), splash screen через `core-splashscreen`, три темы (светлая, тёмная,
системная), **6 языков** интерфейса, включая арабский с полной поддержкой
**RTL**. Сборка на **Gradle** (Kotlin DSL, version catalog).
