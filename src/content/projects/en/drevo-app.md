## What it is

An **Android** mobile app for the **Drevo** encyclopedia, published on Google
Play. It gives **offline access** to the encyclopedia's articles — the database
ships as a separate package via **APK Expansion**, updated monthly with a delta
patch.

## Stack

**Android SDK** (minSdk 24, targetSdk 36), code in **Java** and **Kotlin**, UI on
**Material Components**. **Google Play Billing** for donations, **Firebase
Analytics**, an offline database via **APK Expansion** (downloader library),
**Gson**. Built with **Gradle**.

## My part

Entirely my own project — from development to publishing and support on Google
Play.
